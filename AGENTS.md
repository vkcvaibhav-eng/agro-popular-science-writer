# Agro Popular Science Writer instructions

When the user asks for an English agricultural popular-science article, timely article titles, an author-framework recommendation, or APA 7 reference checking:

1. Read and follow `plugin/agro-popular-science-writer/skills/agro-popular-science-writer/SKILL.md`.
2. Read the linked APA 7 and editorial-framework references before formatting citations or applying a named framework.
3. Use live web research for timely claims and reference verification.
4. Keep the story subject-first. Do not add a regional, location-based or farmer-oriented framing unless the user requests it or the evidence requires it.
